# Keyboard shortcuts

Keyboard-first where it's frequent — the pipeline and the forms. Press `?` on
the pipeline to see this list in-app.

## Pipeline (home)

| Key | Action |
|-----|--------|
| `/` | Focus the search box |
| `n` | New application |
| `j` | Move row selection down |
| `k` | Move row selection up |
| `Enter` | Open the selected application |
| `?` | Show the shortcuts help |
| `Esc` | (in search) clear and blur |

Shortcuts stand down while you're typing in a field.

## Anywhere with a panel or dialog

| Key | Action |
|-----|--------|
| `Esc` | Close the dialog / panel |
| `Cmd/Ctrl + Enter` | Save the current field and close (commits on blur, returns to the pipeline) |

## Forms

- Every field on the application detail screen **saves on blur** — there is no
  Save button.
- Tab order runs top-to-bottom, left column then the ad pane.
- In the new-application dialog, `Enter` in the role field creates and opens it.
